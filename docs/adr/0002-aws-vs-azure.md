# ADR 0002: AWS over Azure

## Status
Accepted

## Context
Cloud provider choice for RDS, compute, storage, and IaC. Azure was the faster path given existing day-job familiarity (West Shore Home uses Azure), but that familiarity is also the problem: Azure is already demonstrated on the resume through that role.

## Decision
AWS.

## Consequences
Most target companies for this job search (Strava, AllTrails, Oura, and similar consumer-product companies) skew AWS or GCP rather than Azure, which tends to show up more in enterprise/.NET-heavy shops, already covered by the existing resume line. Choosing AWS costs some initial unfamiliarity but adds real diversification value instead of restating an already-proven skill.
