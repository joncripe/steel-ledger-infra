# Contributing

## Branch naming
`type/short-description`, e.g. `feat/rds-module`, `fix/security-group-rule`.

## Commits
`TSL-123 short summary`.

## Pull requests
- Fill out the PR template
- `main` is protected, CI must pass before merge
- New infra decision? Add an ADR to `/docs/adr`, don't just describe it in a PR

## Review
Solo for now, self-review before merge, required by branch protection.
